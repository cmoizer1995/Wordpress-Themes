# CMUK Inspired Elementor Theme v1.0.1

A lightweight WordPress theme inspired by GOV.UK and CMUK styling, built for Elementor compatibility with a clean responsive header, mobile accordion navigation, and customizable footer branding.

---

## Features

- Full Elementor compatibility
- Responsive desktop and mobile header
- Mobile accordion navigation
- Left-aligned site title
- Right-aligned desktop navigation
- Full-width stretched header layout
- 10px edge spacing system
- Responsive mobile menu
- Accordion dropdown icons aligned to far-right
- Custom footer branding
- Dynamic WordPress Site Title in footer
- Footer auto displays:

  `© YEAR Site Title | Made with love by Connor Moizer`

- Connor Moizer footer link points to:

  https://connormoizer.com

- Header background colour customizer support
- Header text colour customizer support
- Footer background colour customizer support
- Footer text colour customizer support
- Footer text centered by default
- Mobile-friendly layout
- 16px standard typography sizing
- Site title optimized sizing
- Clean hover-free navigation styling
- Stable accordion behaviour
- Removed unnecessary alignment settings from Customizer
- Plug-and-play installation

---

## Installation

1. Download the ZIP
2. Go to WordPress Admin
3. Appearance → Themes
4. Upload Theme
5. Activate

---

## Recommended Plugins

- Elementor
- Elementor Pro (optional)

---

## Customizer Options

Available in:

`Appearance → Customize → CMUK Theme Settings`

Includes:

- Header background colour
- Header text colour
- Footer background colour
- Footer text colour
- Footer text

---

## Mobile Navigation

The mobile menu includes:

- Accordion dropdown support
- Right-aligned dropdown arrows
- Left-aligned menu text
- Responsive spacing
- Full-width touch-friendly rows

---

## Footer Behaviour

Footer automatically uses the WordPress Site Title.

Example:

`© 2026 Connor Moizer | Made with love by Connor Moizer`
